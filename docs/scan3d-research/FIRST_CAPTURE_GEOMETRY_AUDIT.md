# First live capture: geometry failure analysis

This note concerns one user-provided smartphone capture. It is an engineering diagnosis, not a validation dataset or a clinical assessment. No reference mesh, repeat capture, per-tooth labels, or measured accuracy is available: `DATASET_UNAVAILABLE` for Phase 13 evaluation.

The 15.3-second portrait video decoded correctly at 1080 × 1920. Acquisition retained 18 frames. The original sparse SfM implementation selected frames 357 and 457 by maximum accepted point count, triangulated 86 points, and connected them into 94 triangles. Direct reprojection of those 86 points onto the first selected frame found all of them below the mouth, on chin/clothing/background, and none in the visible tooth area. The mouth also changed substantially between these frames. Thus the displayed geometry was real image-derived geometry, but not dental geometry. Low reprojection error did not establish dental identity.

The mesh algorithm interpolates one image-plane point set; it does not segment teeth, perform dense multi-view fusion, or prove arch/tooth coverage. A dry run of the new additional-view PnP check registered seven frames on this same capture, while the mesh remained the same 86-point non-dental surface. More registered frames alone cannot establish dental reconstruction. The new report records observed connected components, used/isolated vertices, image-space feature bounds, best pair, and additional-view evidence so that these limitations can be inspected without inferring anatomy.

The capture workflow now guides a separate rear-camera arch scan with closer overlapping tooth views. The backend rejects sparse geometry as insufficient instead of publishing it as a ready mesh. The original image-derived mesh can still be shown through an authenticated, checksum-verified diagnostic-only route so operators can inspect failure geometry; measurement, segmentation, and ready-asset publication remain disabled. The next substantive reconstruction milestone requires dental-region evidence (manual annotation or a validated detector), stable rigid-scene capture, calibrated camera geometry, dense multi-view surface reconstruction, and per-tooth coverage checks. Each must be assessed on real repeated captures and reference meshes before claims of tooth completeness or accuracy.

`IMPLEMENTED ≠ EXPERIMENTALLY VALIDATED ≠ CLINICALLY VALIDATED`.
