## 5. Numbers That Cannot Be Reported As Measured Results

The following numbers from the manuscript **cannot** be reported as empirical measurements of system performance:

1. **Queue time `99.09 ms` (CDSS baseline n=5):**  
   Purely synthetic. It was generated by `80 + Math.random() * 40` in `run-cdss-async-latency.js:152`. No queueing mechanism, message broker, or job queue existed in the code path.
2. **Inference time `408.07 ms` (CDSS baseline n=5):**  
   Synthetic ratio. It was derived by multiplying a synchronous `/analyze` round trip by a hard-coded constant `0.94` in `run-cdss-async-latency.js:153`.
3. **Persistence time `26.05 ms` (CDSS baseline n=5):**
