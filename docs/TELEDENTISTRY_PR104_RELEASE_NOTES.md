# Teledentistry PR104 Release Notes

## Implemented in PR104

- Mobile clinic discovery skeleton loading.
- Saved clinics, favorite state, recently viewed clinics, and persistent clinic filters.
- Operating-hours accordion on clinic detail.
- Slot availability heat indicators, virtual consultation duration selector, smart empty slot state, and selected-slot confirmation bar.
- Optional pre-session health form during booking confirmation.
- Dentist web today-session dashboard with chat, video, and pre-session form quick actions.
- Appointment list/detail UX improvements, sync freshness indicator, countdown, and lifecycle timeline.
- Payment expiry countdown and booking success confetti.
- Patient Teledentistry low-bandwidth warning, audio-only prompt, and connection diagnostics sheet.
- Review category ratings, review tags, and optional photo picker metadata/local preview handling.

## Not Yet Fully Implemented

- Map view toggle.
- In-app Midtrans Snap WebView.
- Native calendar integration.
- Picture-in-picture video mode.
- Virtual background.
- Chat search and jump.
- Chat reactions.
- AI symptom checker.
- AI SOAP note generation.
- Actual review photo upload pipeline.

These roadmap items must not be described as completed until their backend, mobile/web UI, tests, and QA flows are implemented.
